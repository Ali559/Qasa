# Payment wallet logos

Logos of the three wallets Premium is paid with. They are the wallets' own trademarks, used
only to show which payment methods Qasa accepts. Don't recolour or redraw them.

| File | Source (fetched 2026-11-03) |
| --- | --- |
| `fib-icon.png` | First Iraqi Bank app icon, App Store listing (id 1545549339) |
| `fib-wordmark.svg` | Header logo on fib.iq (`header-mobile-logo.svg`) |
| `fastpay-icon.png` | FastPay Wallet app icon, App Store listing (id 1255784969) |
| `fastpay-wordmark.png` | Logo on fast-pay.iq (`img/clogo.png`) |
| `superqi-icon.png` | SuperQi app icon, App Store listing (id 6450545056); grey edge from the store render cleaned to black |

Copies used by the products (192 px icons):

- Landing: `apps/landing/public/wallets/`
- iOS: `apps/ios/qasa_ios/Assets.xcassets/Wallet*.imageset`
- Android: `apps/android/app/src/main/res/drawable-nodpi/wallet_*.png`

If a wallet changes its branding, replace the file here first, then the copies.
